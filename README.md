A rich narrative **Personality Module** for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** where an innocent mortal shell is secretly hijacked by an ancient, starving succubus entity.

---

## 🎮 Features

- **Unique Persona:** Blends sweet human affection with ravenous, ancient demonic desires.
- **Story Dialogue Branches:** Complete set of narrative dialogue sequences for daily interactions, headpats, and intimate encounters.
- **Custom Status Coroutine:** Evaluates affection, cravings, and behavioral progression dynamically.
- Compatible with MDRG version **v0.97.12** (Target: `0.90.16`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/real-succubus-pm/releases) tab.
