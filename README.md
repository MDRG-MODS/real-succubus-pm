A rich narrative **Personality Module** for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** where an innocent mortal shell is secretly hijacked by an ancient, starving succubus entity.

---

## 🎮 Features

- **Unique Persona:** Blends sweet human affection with ravenous, ancient demonic desires.
- **Story Dialogue Branches:** Complete set of narrative dialogue sequences for daily interactions, headpats, and intimate encounters.
- **Custom Mechanics:** Custom status evaluation coroutine managing affection, craving, and behavioral escalation.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.90.16`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/real-succubus-pm/releases) page and download `Real succubus.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `Real succubus.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/Real succubus/mod.json
   ```
4. Launch the game and equip the module in the bot's personality slot.
